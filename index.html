唤醒 YYOU：如何获取 API 密钥？

为了保证你的对话隐私和能量供应，YYOU 需要连接到你自己的 Coze 能量站。

①
访问能量站

前往 Coze.cn（国内版）或 Coze.com（国际版）并登录。

②
进入设置

点击左下角头像，进入个人设置 (Personal Settings) -> 令牌 (API Keys)。

③
生成令牌

点击生成新令牌 (Generate new token)，起个名字（比如"给 YYOU 的零食"），然后复制那串长长的代码。

④
完成连接

回到 YYOU 界面，点击右下角小齿轮 ⚙️，把代码粘贴进去并保存。

交互秘籍：怎么玩转 YYOU？

🎙️
对讲机模式

长按右下角的麦克风图标，看到紫色脉冲波纹出现后开始说话，松手即发送。你会看到文字实时跳进输入框。

⚡️
情绪共振

试着在对话里输入 ⚡️ 或 ☁️，观察背景的动态弥散光晕是如何随之流转的。

✨
流式阅读

YYOU 回复时会像真人一样停顿和思考，请享受文字一段段跃然纸上的节奏感。
